# 正式界面设计要求

日期：2026-10-04。技术与视觉基线：Avalonia、Material 3 Expressive、Material You 动态配色。

## 用户已确认的要求

用户认可详情页草图的大致交互方向，并要求正式界面认真设计控件位置和视觉布局。正式设计围绕图片浏览、常驻作品信息与独立悬浮收藏组织页面；浏览模式、重力开关及灵敏度等配置归入设置或次级菜单。

## 详情页的设计方向

- 图片成为主要视觉内容，布局根据画面比例、屏幕方向与窗口尺寸调整。
- 标题和作者保留在常驻信息区，标签、简介及更多作品信息进入可展开内容。
- 收藏保持独立悬浮入口，左右侧具有适合单手触达的吸附位置；处理中与完成状态保持一致的空间和视觉关系。
- 模式配置采用集中设置入口，详情页保留查看作品所需的操作；模拟倾斜与翻图演示控件属于交互草图的说明界面。
- 信息区、图片区与悬浮按钮的手势边界明确，图片缩放、翻图、切作品及抽屉操作各自具有连续的反馈。

## 视觉与布局验收

- M3 Expressive 的颜色角色、字体层级、形状、状态层与动效在各页面中统一应用。
- 动态配色、明暗主题与中文字体放大保持清晰的信息层级。
- 内容、触摸区域、系统安全区和单手触达共同决定尺寸与间距。
- 长标题、较多标签、多图作品、加载中、失败重试和收藏处理中具有完整的布局状态。
- 手机竖屏、横屏及较宽窗口分别审阅布局；主题库同时验证组件状态与输入方式。
